# 広告（AdSense）の番号の入れ方

審査に通ったあと、**広告ユニットの番号を1行ずつ書き写すだけ**で広告が出ます。
枠を置く場所とルールはコード側で決めてあるので、番号以外はさわる必要がありません。

## 1. AdSense の管理画面で広告ユニットを作る

「広告」→「サイトごと」ではなく **「広告ユニットごと」** を開き、
**ディスプレイ広告** を4つ作ります。名前は分かればなんでも構いません（例のとおりで大丈夫です）。

| 作る広告ユニットの名前（例） | どこに出るか |
|---|---|
| `sij-article-top` | 記事の本文がはじまる前 |
| `sij-article-bottom` | 記事の本文の後、出典の前 |
| `sij-visa-detail` | 在留資格のページ、説明の後 |
| `sij-top` | トップページ、入口タイルの下 |

作ると、コードが表示されます。その中の **`data-ad-slot="..."` の数字**（10桁くらい）が必要な番号です。
コード全体をコピーする必要はありません。

## 2. 番号を `data/ad-slots.json` に書く

```json
{
  "article-top": "1234567890",
  "article-bottom": "2345678901",
  "visa-detail": "3456789012",
  "top": "4567890123",
  "guide-index": ""
}
```

空のままにした場所には、広告は出ません。**あとから1つずつ増やせます。**

## 3. 書き出して公開する

```bash
cd scraper
npm test            # 置き場所のルールを確かめる
npm run pages       # 在留資格のページ
npm run articles    # 記事のページ
npm run static      # 固定ページ
```

変更をコミットして main にマージすると公開されます。
（Claude Code に「広告の番号を入れた」と伝えれば、ここまでやります）

## 守っているルール（コード側で機械的に見張っています）

- **節の中には広告を入れない。** 各節は公式の引用で終わるため、節の中に入れると
  引用の真下に広告が出て、どれが公式の文言か分からなくなる
- **1ページに2つまで**
- **「広告」と分かる表示を必ず添える**
- **番号が空のあいだは、枠そのものを書き出さない**（審査中に空欄が出ない）

ルールは [scraper/lib/ads.js](../scraper/lib/ads.js)、見張りは
[scraper/test/ads.test.js](../scraper/test/ads.test.js) にあります。
